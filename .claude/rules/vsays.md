# Voice chat and vsays

Key layer mechanics (number row, `reset<Layer>`, popups): `.claude/rules/layers.md`. Vsay ids, variants and stock texts: `default/scripts/vsays/README.MD` (no need to open a pk3); command syntax: `docs/commands.md`, nitmod: `docs/commands_nitmod.md`.

| File | Status |
|---|---|
| `voicechat.cfg` | `v` opener, `resetVoiceChat`, execs the three files below |
| `vsays/chat.cfg` | stock categories: per category `vsay<Cat><n>` (text), `c<Cat><n>` (key action, ends with `vstr resetVoiceChat`), `chat<Category>`, `bindNumbers<Menu>`, `echo<Item>` |
| `vsays/chat_custom.cfg` | TAB page: `cCus<n>` exec a server's entry page |
| `vsays/vsays_custom.cfg` | texts of the class vsays (`class/cs_classcripts.cfg`); live, not in version control |
| `vsays/chat_shortcuts.cfg` | nitmod only (exec'd by `mods/nitmod/mod_general.cfg`): redefines some `vsay<Cat><n>` of `chat.cfg` with `[S]`-style shortcuts. A text changed in `chat.cfg` may have its copy here |
| `vsays/servers/<clan>/*.cfg` | server voice chat pages; generated, not in version control, exec'd when opened |
| `vsays/server.example.cfg` | template (server overrides of the stock vsays), not live |
| `vsays/chat_function.cfg` | not live (exec commented out in `chat.cfg`) |
| `vsays/vsaycolors.tsv` | record of `tools/vsaycolors.py` (colors of the last apply, reviewed texts): never edit |

- Server pages are generated by `tools/voicemenu.py <clan> <pk3> [tag]` (the command per clan is in the comments of `chat_custom.cfg`): edit only the vsay text in their `bind` lines (a rerun keeps it per vsay and echoes it); everything else is rewritten from the server menu. Don't read the ~70 pages; one file (`servers/eg/eg_main_0.cfg`) shows the format.
- Server pages bind keys directly when exec'd, no aliases: cvars are capped at `MAX_CVARS` (2048) and nitmod already uses ~1900. Every page runs `vstr unbindNumbers` before its binds, so no parent page action remains.
- Colors: never pick color codes by hand. Texts use the `VSAY_*` colors and echo menus the `MENU_*` colors of `settings.conf`; write the text, then use the vsay-highlight skill (`tools/vsaycolors.py apply`).
- A vsay text is one chat line: at most 149 characters including color codes, no `;` or `"` inside.
- nitmod sends the text as a normal chat line and takes no variant number (`vsay <n> <id>` is legacy only).
