# ET: Legacy scripts wiki

Background documentation for the [etlegacy-scripts](https://github.com/JoAllg/etlegacy-scripts) profile.

- [Game knowledge](gameplay.md): console, FPS/network settings, recoil/spread, tips
- [Autoexec behavior](autoexec.md): config load order, which mods run map/team/class autoexecs
- [Config scripting](scripting.md): syntax, patterns and limits
- [Limitations](limitations.md): what config scripts cannot do (state out of sync, FPS dependent waits) and the workarounds
- [Script conventions](conventions.md): naming and file structure
- [Commands](commands.md): legacy console commands, chat/vsay syntax
- [nitmod commands](commands_nitmod.md): differences to legacy
- [Location files](locations.md): map location names, lookup order and format in legacy and nitmod
- [Key names](keybinds.md): `bind` key names incl. mouse and German layout
- [Color codes](colors.md): `^` color codes with hex values
- [Special characters](special_chars.md): ET font character map
