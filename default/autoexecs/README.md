These only work in etlegacy, etpub, silEnT, ETJump and nitmod (see docs/autoexec.md for details per mod) Their usage is therefore on purpose limited to where they bring additional value for these mods. Which is mostly spawnpoints


`deploy.sh` symlinks them into `<fs_homepath>/etmain/`, which is in the search path of every mod. The spawn selecting keys are in `scripts/spawnscript.cfg`.

Rules for these files (layout, what they must set): `.claude/rules/autoexecs.md`.
